# Answering-Sheet-OUC
中国海洋大学Python程序设计小组作业，机读答题卡识别与成绩统计系统

## 项目概述

随着中国信息技术的进步，答题卡在各学校的考试中起到重要的作用。本组Python项目就机读答题卡的识别和成绩统计系统进行研究开展。项目功能流程：预处理图像并校正答题卡的方向、确定每个填涂方块的位置、识别答题卡上填涂方块填涂与否、判定答案对错、统计并输出成绩及分析（个人分数、题目答题情况等）。

@FLYER2048 负责答题卡识别部分，Shawn负责分数统计与计算，Ariel & Emma负责答题报表输出和报告撰写。所有团队成员做出了同等贡献。

## 依赖库
该文件使用以下库：
- `PIL (Pillow)`: 用于图像处理。
- `os`: 用于文件和路径操作。
- `csv`: 用于数据读写实现 CSV 文件功能。
- `matplotlib.pyplot`: 用于绘图和数据可视化。

## 主要参数
- `black_degree`: 用于判断像素是否属于黑色的灰度值上限，默认为 180。
- `black_rate`: 用于判断区域填涂有效的下限比率，默认为 0.64。

## 函数介绍

### 辅助函数
- **is_image_file(filename)**: 判断文件是否为图像文件。

### 图像处理及填涂判断
- **splitMark(x1r, x2r, y1r, y2r)**: 在指定位置绘制蓝色边框以便于标记。
- **splitMarkOPos(x1op, x2op, y1op, y2op)**: 用于在图像上标记缺考和准考证号位置。
- **isBlack(R, G, B)**: 判断给定 RGB 色值是否为黑色。
- **isFilled(x1op, x2op, y1op, y2op)**: 判断填涂区域的有效性。
- **find_largest_circle_radius(x, y)**: 寻找特定坐标周围的最大黑色圆半径。

### 答题卡处理
- **find_3_marks()**: 识别图像中三个位置标志红点。
- **find_mark(path, filename)**: 从指定图像中找到标志位。
- **mark_blocks(path, filename)**: 识别填写的准考证号和选择项，并标记图像。
- **transforms_2D(path, filename, pos)**: 对图像进行透视变换。

### 数据分析
- **Distinguish()**: 识别指定路径下所有图像，处理并输出分析结果。
- **Assess(ANS)**: 对答题数据进行评分及统计分析。
- **Analyse(ANS, AS)**: 进行选项统计分析、分数排名和平均分计算。

### 数据输出
- **DrawGraph(ANA)**: 绘制每道题的选项分布柱状图。
- **PrintTable(ANS, AS, ANA)**: 将分析结果输出为 CSV 文件，包含学生答题情况、得分情况和选项分析等。

## 使用说明
该程序适合用于自动化处理学校的答题卡，用户需要准备好图像文件并将其放置在指定目录中，然后运行程序即可获得解析结果和统计数据。生成的标记图像和 CSV 文件会保存在相应的输出目录中。

## 注意事项
- 在使用该程序之前，请确保已安装所需的 Python 库，例如 `Pillow` 和 `matplotlib`。
- 本程序的参数设置（如 `black_degree` 和 `black_rate`）可能需要根据实际图像情况进行调整，以优化识别效果。
